# Changelog

## 0.4.2

- Rename the extension to Easy Code Runner — External Terminal.
- Add GitHub Actions tests, VSIX builds, and tag-based releases with optional Marketplace trusted publishing.

## 0.4.1

- Added a branded README, extension icon, and Marketplace banner metadata.
- Split configuration and language references into dedicated guides.
- Added contributor guidance and issue templates.

## 0.4.0

- Added Programming Language dropdown and editable Run Config in Settings.
- Added separate saved commands for each language and OS.
- Added filename placeholders and compile-then-run command chains.

## 0.3.0

- Added 64 runner definitions covering Code Runner's default mappings.
- Added custom executor overrides and platform-specific tool choices.
- Fixed Windows batch execution for paths with spaces and shell characters.

## 0.2.1

- Added Run Key presets and custom shortcut configuration from Settings.

## 0.2.0

- Added terminal selection for Windows, Linux, BSD, and macOS.
- Added custom terminal arguments and pause-after-run settings.

## 0.1.4

- Changed execution to a separate external console.

## 0.1.3

- Restored the original failure banner and ASCII cat artwork.

## 0.1.2

- Set F12 as the default shortcut.

## 0.1.0

- Converted the original Python/batch launcher into a VS Code extension.
